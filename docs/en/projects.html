Ongoing research

Procedural Memory Lab

  • Python
  • pytest
  • language models
  • experimental evaluation
View the code on GitHub

An experimental case study on whether small language models improve by retrieving procedures, or merely by seeing similar answers again. The test bed is Python functions with real bugs and automated pytest checks, compared across four configurations.

How to run it

  1. Python 3.11 or newer and the dependencies listed in requirements.txt are required.
  2. The guided setup is started with python -m cognitive_rpg.settings_wizard.
  3. The experiment is launched with python -m cognitive_rpg.experiment.experiment_0. Mock adapters are available to develop without paid calls.

An independent research project, not a peer-reviewed paper. The code is visible for evaluation; reuse is not permitted.

University project

VinylWaves

  • Java 21
  • Jakarta Servlet and JSP
  • MySQL
  • Maven
View the code on GitHub

A Java web shop for vinyl records, CDs and turntables, developed by a team of three for the Web Software Technologies course. It includes a catalogue with search and filters, accounts, cart, orders and product management.

How to run it

  1. Import the vnl_db.sql schema into MySQL and set up the local connection expected by the DAO layer: credentials are not in the repository.
  2. From the vnl folder run ./mvnw package to build the WAR file.
  3. Deploy the WAR to a Jakarta Servlet compatible container, for example Tomcat 10.

Team project: each contribution is credited in the README. The code is visible for evaluation; reuse is not permitted.

ASES, Architecture and Software Evidence Scanner

  • Python
  • code analysis
  • software architecture
View the code on GitHub

A scanner that reconstructs what a codebase actually does before recommending how it should change: it classifies the files, collects facts, keeps counter-evidence and only then infers. It analyzes Java, Python, TypeScript and frontend projects.

How to run it

  1. Python 3.11 or newer and an active virtual environment are required. From the repository root: python -m pip install -e "./runtime[documents]".
  2. The interface opens in the browser with ases ui, or a project is analyzed from the terminal with ases scan /path/to/project --out current.ases.
  3. To compare a new analysis with the previous one: ases scan /path/to/project --out next.ases --baseline current.ases.

A personal project still in development. The code is visible for evaluation; reuse is not permitted.
