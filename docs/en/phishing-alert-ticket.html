Ticket comments

I am escalating this ticket to a level-two SOC analyst. The alert fired on a possible phishing email sent to the HR mailbox. After reading the message and checking the attachment I think it is a real attack and not a false positive.

Here is what does not add up. The sender's display name is "Def Communications", but the message is signed "Clyde West". The sender address is a long string of random characters on a .su domain, which is not what a job applicant would use. The subject and the body have spelling and grammar mistakes ("Egnieer", "Ingergy", "writing for to express"), and the company name in the greeting is not spelled like the domain the message was sent to. The email says a resume and a cover letter are attached, but the only attachment is bfsvc.exe, which is an executable file. The body also gives a password to open it, which is a known way to keep mail scanners from looking inside a file.

The file hash in the ticket matches a known malicious file in the threat intelligence lookup. The ticket says the user may have opened the attachment, and until someone shows otherwise I am treating that machine as compromised. The alert severity is medium, but a malicious file that may have been run is more serious than that, so I suggest raising it to high. Level two should isolate the host, check what the file did once it ran, and look for other copies of this email in other mailboxes.
