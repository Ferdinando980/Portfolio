I am a Computer Science student at the University of Salerno. I care about software that can be checked: I write code, but I also like to document it, measure it and find out where it breaks.

I have built web applications in Java, worked in a team on a project followed from requirements analysis to code, and run an independent research project in Python with automated checks and controlled comparisons. Alongside that I completed the Google Cybersecurity Certificate, which is where the case studies on this site come from.

Before all this I was a head coach in an E-Sports team. Coordinating people, giving clear feedback and keeping a tidy working environment are things I bring to technical work too.
