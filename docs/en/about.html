Training

Google Cybersecurity Certificate

The program, developed by Google and offered on Coursera, introduces the foundations of cybersecurity: risk management, network security, Linux and SQL, incident detection and response. It requires no prior knowledge.

Provider
Google, through Coursera
Level
Beginner, no prerequisites
Duration
About 170 hours of instruction
Format
Lessons, assessments and hands-on labs

Roles it prepares for

  • Cybersecurity analyst
  • Security analyst
  • SOC (Security Operations Center) analyst
  • Information security analyst
  • IT security analyst
  • Cyber defense analyst

These are the roles listed on the course page on Coursera. The certificate prepares for these roles but does not replace experience. The program also prepares for the CompTIA Security+ exam, which is a separate certification.

The courses in the program

  1. Foundations of Cybersecurity
    The basics of the job: how attacks affect businesses, security ethics and the analyst's tools.
  2. Play It Safe: Manage Security Risks
    Threats, risks and vulnerabilities, security frameworks, SIEM tools and response playbooks.
  3. Connect and Protect: Networks and Network Security
    Network types and components, data transmission, intrusion defense and system hardening.
  4. Tools of the Trade: Linux and SQL
    Operating systems, the command line, Linux file management and SQL queries on databases.
  5. Assets, Threats, and Vulnerabilities
    Asset classification, attack surface, common threats and threat modeling.
  6. Sound the Alarm: Detection and Response
    Incident containment and recovery, packet analysis, IDS signatures and logs, investigations with a SIEM.
  7. Automate Cybersecurity Tasks with Python
    Python for security tasks: functions, regular expressions, reading and writing files, debugging.
  8. Put It to Work: Prepare for Cybersecurity Jobs
    Incident escalation, community engagement and interview preparation.
  9. Accelerate Your Job Search with AI
    Identifying your skills, organizing applications, building a resume and a job search plan, and practicing interviews.

The nine courses of the program, as listed on Coursera.

The case studies on this site come from the course exercises and cover in particular network traffic analysis, incident response, risk assessment, access control and compliance.
