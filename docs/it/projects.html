Ricerca in corso

Procedural Memory Lab

  • Python
  • pytest
  • modelli linguistici
  • valutazione sperimentale
Vedi il codice su GitHub

Caso di studio sperimentale per capire se i modelli linguistici piccoli migliorano recuperando procedure, oppure se si limitano a rivedere risposte simili. Il banco di prova sono funzioni Python con bug reali e verifiche automatiche con pytest, confrontate in quattro configurazioni.

Come eseguirlo

  1. Servono Python 3.11 o superiore e le dipendenze elencate in requirements.txt.
  2. Si avvia la configurazione guidata con python -m cognitive_rpg.settings_wizard.
  3. Si lancia l'esperimento con python -m cognitive_rpg.experiment.experiment_0. Per sviluppare senza chiamate a pagamento sono disponibili adattatori simulati.

Progetto di ricerca indipendente, non una pubblicazione sottoposta a revisione. Il codice è visibile per valutazione; il riutilizzo non è consentito.

Progetto universitario

VinylWaves

  • Java 21
  • Jakarta Servlet e JSP
  • MySQL
  • Maven
Vedi il codice su GitHub

Negozio web in Java per vinili, CD e giradischi, sviluppato da un gruppo di tre persone per il corso di Tecnologie Software per il Web. Comprende catalogo con ricerca e filtri, account, carrello, ordini e gestione dei prodotti.

Come eseguirlo

  1. Importare lo schema vnl_db.sql in MySQL e configurare la connessione locale attesa dal livello DAO: le credenziali non sono nel repository.
  2. Dalla cartella vnl eseguire ./mvnw package per creare il file WAR.
  3. Distribuire il WAR in un container compatibile con Jakarta Servlet, per esempio Tomcat 10.

Lavoro di gruppo: ogni contributo è indicato nel README. Il codice è visibile per valutazione; il riutilizzo non è consentito.

In sviluppo

ASES, Architecture and Software Evidence Scanner

  • Python
  • analisi del codice
  • architettura software
Vedi il codice su GitHub

Scanner che ricostruisce ciò che un codice fa davvero prima di proporre come dovrebbe cambiare: classifica i file, raccoglie i fatti, conserva le prove contrarie e solo dopo deduce. Analizza progetti Java, Python, TypeScript e frontend.

Come eseguirlo

  1. Servono Python 3.11 o superiore e un ambiente virtuale attivo. Dalla radice del repository: python -m pip install -e "./runtime[documents]".
  2. Si apre l'interfaccia nel browser con ases ui, oppure da terminale si analizza un progetto con ases scan /percorso/del/progetto --out attuale.ases.
  3. Per confrontare una nuova analisi con la precedente: ases scan /percorso/del/progetto --out successiva.ases --baseline attuale.ases.
